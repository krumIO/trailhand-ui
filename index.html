Theme Toggle Example

This demo shows the theme toggle component in action.

The theme automatically matches your system preference, but you can override it using the toggle above.

How it works

  • CSS uses @media (prefers-color-scheme: dark) for system preference
  • Toggling adds .theme-light or .theme-dark class to body
  • Body classes override the media query (higher CSS specificity)
  • Your choice is saved to localStorage

Test it out

Try toggling the switch above to see the theme change. Your preference will be remembered when you return!

To reset to system preference: Open console and run localStorage.removeItem('user-theme-preference') then reload.
